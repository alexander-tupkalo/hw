# Каталог товарів

Невеликий навчальний проєкт — каталог товарів, створений за допомогою JavaScript та архітектури MVC.

## Можливості

- Перегляд списку товарів.
- Пошук товарів за назвою.
- Перегляд детальної інформації.
- Додавання, редагування та видалення товарів.
- Збереження даних у `localStorage`.

## Технології

- HTML
- JavaScript (ES6+)
- Bootstrap 5
- localStorage

## Структура проєкту

```text
src/
├── index.html
├── view.html
├── create.html
├── edit.html
└── scripts/
    ├── controllers/
    ├── data/
    ├── models/
    ├── pages/
    ├── utils/
    └── views/
```

## Запуск

1. Склонуйте репозиторій.
2. Встановіть залежності командою `npm install`.
3. Відкрийте `src/index.html` через локальний сервер, наприклад Live Server у VS Code.
